# Retrieve the initial conditions and parameters for a given biome

Internal helper function for biome functions.

## Usage

``` r
get_biome_inits(core, biome)
```

## Arguments

- core:

  Hector core

- biome:

  Name of biome for which to retrieve data

## Value

Named numeric vector of biome initial conditions and parameters
