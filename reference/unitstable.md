# A data.frame containing information on all of the Hector variable created by units-data.R used within the getunits function.

A data.frame containing information on all of the Hector variable
created by units-data.R used within the getunits function.

## Usage

``` r
unitstable
```

## Format

A data.frame of 2 columns and 114 rows.

- variable:

  String of the hector variable

- units:

  String of the unit value
