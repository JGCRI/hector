# Hector logging levels

These functions return constants that can be used in
[`newcore`](https://jgcri.github.io/hector/reference/newcore.md) to set
the minimum logging level

## Usage

``` r
LL_DEBUG()

LL_NOTICE()

LL_WARNING()

LL_SEVERE()
```

## Functions

- `LL_DEBUG()`: Set logging at 'debug' level.

- `LL_NOTICE()`: Set logging at 'notice' level.

- `LL_WARNING()`: Set logging at 'warning' level.

- `LL_SEVERE()`: Set logging at 'severe' level.
